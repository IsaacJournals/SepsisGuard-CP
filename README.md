# SepsisGuard-CP

Code and results for the article **"Transporting early sepsis warnings between hospitals: a locked-protocol, bidirectional evaluation of calibration, conformal coverage, alarm burden and local adaptation"** (Ayesha A, Isaac RA, Sadiq Ali AJ, Gnana Gandhi SM; submitted to *Artificial Intelligence in Medicine*).

SepsisGuard-CP is a transport protocol for early sepsis warning models: past-only temporal features, a primary model chosen by a pre-specified rule, Platt recalibration, class-conditional (Mondrian and patient-level) split conformal prediction, and an alarm threshold fixed by a false-alarm budget. It is evaluated from hospital A to B and from B to A on the PhysioNet/Computing in Cardiology Challenge 2019 data.

## How to reproduce

1. Open `notebook/SepsisGuard_CP.ipynb` in Google Colab (standard CPU runtime is sufficient).
2. In Cell 1 choose `RUN_MODE`:
   - `SMOKE_TEST` – small subset, about 10–15 min, checks that everything runs (not for reporting);
   - `STANDARD_RUN` – 8,000 / 5,000 patients, about 1 h;
   - `FULL_PAPER_RUN` – all 40,336 stays, three seeds, 1,000 bootstrap resamples; this produced the reported results.
3. Run all cells. Outputs are written to Google Drive under `SepsisGuard_CP_outputs/<RUN_MODE>/` (tables, figures, `RUN_SUMMARY.md`, `MODEL_CARD.md`); every stage is checkpointed, so an interrupted session resumes from the last finished step.
4. Do not edit Cell 21e: on its first run it writes `PROTOCOL_v9_LOCK.json`, and later runs stop if the protocol text no longer matches the stored fingerprint.

The figure scripts in `manuscript_figures/scripts/` read `results/tables/` and redraw Figs 1–6 and S1–S2 (Figs S3–S4 need the row-level predictions written by the notebook to `results/predictions/`).
