# SepsisGuard-CP

Code and results for the article **"Moving a sepsis early-warning model for intensive care between hospital systems: a bidirectional external validation study with diagnosis of miscalibration and local updating"** (Ayesha A, Isaac RA, Sadiq Ali AJ, Gnana Gandhi SM; manuscript under review).

The study develops a sepsis early-warning model at one hospital system and externally validates it at the other, in both directions, on the PhysioNet/Computing in Cardiology Challenge 2019 data. The pipeline uses past-only temporal features, a primary model chosen by a pre-specified rule, Platt recalibration, class-conditional (Mondrian and patient-level) split conformal prediction and an alarm threshold fixed by a false-alarm budget, under an analysis protocol locked with a SHA-256 fingerprint before analysis. Post hoc analyses examine why the model becomes miscalibrated at the new hospital (prevalence, case mix, recording practice) and how many labeled local patients are needed to update it.

## How to reproduce

1. Open `notebook/SepsisGuard_CP.ipynb` in Google Colab (standard CPU runtime is sufficient).
2. In Cell 1 choose `RUN_MODE`:
   - `SMOKE_TEST` – small subset, about 10–15 min, checks that everything runs (not for reporting);
   - `STANDARD_RUN` – 8,000 / 5,000 patients, about 1 h;
   - `FULL_PAPER_RUN` – all 40,336 stays, three seeds, 1,000 bootstrap resamples; this produced the reported results.
3. Run all cells. Outputs are written to Google Drive under `SepsisGuard_CP_outputs/<RUN_MODE>/` (tables, figures, `RUN_SUMMARY.md`, `MODEL_CARD.md`); every stage is checkpointed, so an interrupted session resumes from the last finished step.
4. Do not edit Cell 21e: on its first run it writes `PROTOCOL_v9_LOCK.json`, and later runs stop if the protocol text no longer matches the stored fingerprint.

The figure scripts in `manuscript_figures/scripts/` read `results/tables/` and redraw the article figures: `figs.py` draws Figs 1, 2, 4, 5, 7 and 8, `figs_diagnosis.py` draws Figs 3 and 6 and Figs S5–S7, and `suppfigs.py` draws Figs S1–S2 (Figs S3–S4 need the row-level predictions written by the notebook to `results/predictions/`).
